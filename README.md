# NHANES Depression Analysis

## Project Overview
This project examines factors associated with depression among 6,337 U.S. adults using data from the 2021–2023 National Health and Nutrition Examination Survey (NHANES).

The analysis explores demographic, socioeconomic, behavioral, and health-related factors associated with depression using statistical and machine-learning methods in R.

## Objectives
- Identify factors associated with depression among U.S. adults.
- Examine relationships between demographic and health characteristics and depression.
- Develop a logistic regression model to evaluate predictors of depression.
- Apply Random Forest analysis to identify important predictors.
- Evaluate model performance using ROC analysis.

## Dataset
**Source:** National Health and Nutrition Examination Survey (NHANES), 2021–2023.

**Sample size:** 6,337 U.S. adults.
